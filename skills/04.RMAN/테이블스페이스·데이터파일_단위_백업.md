```sql
-- 백업 범위를 좁혀 테이블스페이스와 데이터파일 단위로 백업한다.
-- SKIP 옵션의 동작을 확인한다.
-- NOT BACKED UP SINCE TIME 으로 중단된 백업을 이어받는다.
-- 범위를 나눌 때 파일이 누락되는 상황을 재현하고 발견한다.
-- 작업 유형 : 백업 수행(장애 복구 아님)

[세션: RMAN (Target + Catalog 동시 접속)]
REPORT SCHEMA;

CREATE TABLESPACE tbs_ro DATAFILE '/u02/oradata/orcl/tbs_ro01.dbf' SIZE 10M;
12c 버전부터는 RMAN 프롬프트 내에서 별도의 SQL '...' 구문 없이 DDL 문을 직접 실행할 수 있습니다. 복구 카탈로그 접속 상태이므로 구조 변경 직후 카탈로그 자동 동기화(resync)가 일어납니다. (운영 경로 적용)

ALTER TABLESPACE tbs_ro READ ONLY;
생성한 테이블스페이스를 읽기 전용(READ ONLY) 상태로 변경합니다.

[세션: Linux OS Shell]
sqlplus -s / as sysdba <<< "SELECT tablespace_name, status FROM dba_tablespaces ORDER BY tablespace_name;"

[세션: RMAN (Target + Catalog 동시 접속)]
BACKUP TABLESPACE users, tbs13 TAG 'TS_PARTIAL';
데이터베이스 전체가 아닌 특정 테이블스페이스 단위로 백업 범위를 좁혀서 수행합니다.

BACKUP DATAFILE 7 TAG 'DF7_ONLY';

BACKUP DATAFILE '/u02/oradata/orcl/tbs13_01.dbf' TAG 'DF_BY_PATH';
데이터파일 번호(file#)가 아닌 실제 물리적 경로를 직접 지정하여 해당 파일만 개별적으로 백업합니다.

BACKUP DATABASE SKIP READONLY TAG 'SKIP_RO';
전체 백업을 수행하되, 읽기 전용(READ ONLY) 상태인 데이터파일은 백업 대상에서 제외(SKIP)합니다. 읽기 전용 파일은 내용이 변하지 않으므로 매일 백업할 필요 없이 한 번만 받아두면 됩니다.

ALTER TABLESPACE tbs13 OFFLINE;
해당 테이블스페이스를 오프라인 상태로 변경합니다.

BACKUP DATABASE SKIP OFFLINE TAG 'SKIP_OFF';
전체 백업 수행 시 오프라인(OFFLINE) 상태인 데이터파일을 건너뜁니다. 단, 읽기 전용과 달리 오프라인 파일은 향후 온라인으로 변경 시 데이터가 바뀔 수 있어 복구 가능성이 위태롭다는 경고(RMAN-06060)를 발생시킵니다.

ALTER TABLESPACE tbs13 ONLINE;

BACKUP DATABASE NOT BACKED UP SINCE TIME 'SYSDATE-1/24' TAG 'RESUME';
지정한 시점(예: 최근 1시간 전) 이후에 백업된 이력이 없는 파일만 골라서 백업합니다. 야간 백업 작업이 모종의 이유로 중간에 실패하거나 끊겼을 때, 처음부터 다시 전체를 백업하지 않고 남은 파일만 이어받기 위해 유용하게 사용합니다.

CREATE TABLESPACE tbs_new DATAFILE '/u02/oradata/orcl/tbs_new01.dbf' SIZE 10M;

BACKUP TABLESPACE users, tbs13, tbs_ro TAG 'ROTATION';

REPORT NEED BACKUP;

REPORT SCHEMA;

BACKUP TABLESPACE tbs_nwe TAG 'ROTATION';
일부러 오타(tbs_nwe)를 발생시켜 백업을 시도합니다. 카탈로그에 존재하지 않는 테이블스페이스 이름을 지정하면 RMAN-20202 오류가 발생함을 확인합니다. 테이블스페이스 단위로 쪼개어 백업 스크립트를 작성하면 구조 추가/변경 시 이처럼 누락이나 오타로 인한 백업 실패 위험이 존재합니다.

BACKUP TABLESPACE tbs_new TAG 'ROTATION';

REPORT NEED BACKUP;

LIST BACKUP SUMMARY;

LIST BACKUP OF TABLESPACE tbs_ro SUMMARY;
특정 테이블스페이스(tbs_ro)에 대해서만 백업본 목록을 필터링하여 요약 조회합니다.

RESTORE TABLESPACE tbs_new PREVIEW SUMMARY;
실제로 복원을 수행하지 않고, 해당 테이블스페이스를 복원하기 위해 어떤 백업 피스들과 아카이브 로그 파일들이 필요한지 가상으로 미리 점검(Preview)하여 결과를 리포트합니다.

[세션: SQL*Plus (SYSDBA)]
DROP TABLESPACE tbs_new INCLUDING CONTENTS AND DATAFILES;
실습으로 생성했던 테이블스페이스와 연관된 물리적 데이터파일을 디스크에서 완전히 삭제하여 실습 환경을 원래대로 정리합니다.

DROP TABLESPACE tbs_ro INCLUDING CONTENTS AND DATAFILES;
```
