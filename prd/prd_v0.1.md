## 1. 프로젝트 배경 및 목적 (Background & Objectives)

- **프로젝트 명:** 자격증공부.com
    
- **기획 배경:** 개발자 본인과 동기들이 SQLD, OCP 등 IT 자격증 기출문제를 효율적으로 학습할 수 있는 실질적인 CBT(Computer-Based Test) 플랫폼의 필요성 대두.
    
- **비즈니스/포트폴리오 목표:** 단순한 프론트엔드 중심의 토이 프로젝트를 넘어, 대용량 기출문제(텍스트, 이미지)를 다루는 **데이터 무결성 방어 및 OCI(Oracle Cloud) 기반 파이프라인 구축 역량**을 증명하는 풀스택/DBA 포트폴리오 완성.
    

## 2. 타겟 유저 (Target Audience)

1. **일반 수험생 (User):**
    
    - SQLD, OCP, 정보처리기사 등 자격증 취득을 목표로 기출문제를 반복 풀이하고자 하는 학습자.
        
    - 자신의 오답 노트와 누적 정답률 통계를 확인하고 싶은 사용자.
        
2. **시스템 관리자 / 출제자 (Admin):**
    
    - 정형화되지 않은 엑셀(Excel) 형태의 기출문제 데이터를 시스템에 대량으로 빠르고 안전하게 업로드해야 하는 관리자.
        

## 3. 핵심 기능 요구사항 (Core MVP Features)

### 3.1. 인증 및 권한 (Auth)

- **소셜 로그인 도입:** 개인정보 보관 리스크 및 비밀번호 분실 문제를 원천 차단하기 위해 자체 회원가입 대신 **카카오 OAuth 2.0 API**를 통한 간편 로그인 제공. (DB에는 카카오 고유 식별자 및 닉네임만 저장)
    

### 3.2. 문제 은행 및 모의고사 (Exam System)

- **다단계 시험 설정:** 학습자가 원하는 환경을 세밀하게 설정할 수 있도록 4단계 모달 제공.
    
    - _Step 1:_ 과목 선택 (예: SQLD, OCP 등)
        
    - _Step 2:_ 시험 유형 선택 (필기 / 실기)
        
    - _Step 3:_ 풀기 방식 선택 (실전 모드 / 연습 모드)
        
    - _Step 4:_ 회차 선택 (예: '23-01' 등 동적 로드)
        
- **OMR 풀이 화면:** 실제 시험과 유사한 UI에서 문제를 풀고 답안을 마킹할 수 있는 기능. 지문과 문제, 그리고 동적으로 구성되는 객관식 보기 제공.
    
- **자동 채점 로직:** 제출된 답안을 DB의 정답과 대조하여 즉시 채점.
    

### 3.3. 학습 통계 및 마이페이지 (My Page)

- **풀이 이력 저장:** 사용자가 제출한 모든 문항에 대한 정답/오답 여부를 로그 테이블에 기록.
    
- **누적 대시보드:** 자격증 및 세부 과목별 총 풀이 문제 수, 정답 수, 정답률(%)을 시각화하여 제공.
    

### 3.4. 관리자 데이터 파이프라인 (Admin Tools)

- **안전한 엑셀 업로드:** 관리자가 기출문제 엑셀을 업로드하면, 운영 DB 오염을 막기 위해 STG(Staging) 임시 대기열을 거쳐 검증된 데이터만 적재되는 시스템.
    

## 4. 핵심 유저 플로우 (User Flow)

1. **[진입]** 메인 랜딩 페이지 접속 → 카카오 계정 로그인.
    
2. **[설정]** 메인 화면에서 응시할 '자격증 카테고리' 클릭 → 팝업 모달창에서 '유형 ➡️ 방식 ➡️ 회차' 순차적 선택.
    
3. **[응시]** OMR 전용 페이지로 라우팅되어 기출문제 풀이 진행 (SPA 기반 화면 전환).
    
4. **[결과]** 최종 답안 제출 → 즉시 채점 및 오답 확인.
    
5. **[복습]** 마이페이지로 이동하여 누적된 과목별 정답률 및 취약점 통계 확인.
    

## 5. 제약 사항 및 비기능 요구사항 (Non-Functional Requirements)

- **성능:** 모의고사 랜덤 추출 시 웹 서버 메모리 부하를 방지하기 위해 DB 엔진 레벨의 분석 함수(`ROW_NUMBER()`)를 활용하여 데이터를 커팅(Cutting)해야 함.
    
- **안정성:** 무거운 지문 이미지(BLOB)로 인한 DB I/O 병목을 막기 위해 이미지는 OCI Object Storage에 분리 적재하고 DB는 URL만 관리.
    
- **배포:** OCI Compute VM 환경에서 Nginx 리버스 프록시와 PM2를 결합하여 24/7 무중단 운영 환경 보장.
